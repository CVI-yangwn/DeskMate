# 今日收尾

目标：用 3–5 句话帮用户关掉今天，而不是复述流水账。

步骤：

1. 先读上下文里已有的「今天的锚点」「最近活动时间线」「最近意图」和「个人 wiki」。
2. 只有缺关键细节时，才调用 `lookup_activity`（默认 240 分钟）补齐。
3. 按三段组织：
   - **今天推进了**：1–3 件有结果的事，写具体对象（哪个报错、哪个页面、哪个文件）。
   - **卡住 / 没做完**：只写有证据的，0–3 件。
   - **明天先做**：只给一件，具体到下一步动作。
4. 结尾问一个具体问题，例如“明天从 failing test 继续，还是先补 README？”
5. 如果用户同意，把“明天先做”用 `remember` 或“记一下”写入；不要擅自写。

边界：不编造成果；没有证据就直说“今天记录不多”；不劝加班，不用“加油”。
