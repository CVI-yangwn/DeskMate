# 周报

目标：让用户能直接粘贴到周报里，同时保留“这是我自己写的”语气。

步骤：

1. 用 `lookup_activity` 按天取最近 7 天：`daysAgo` 从 0 到 6，每次 `minutes: 1440`；一天一天看，不要一次扫七天。
2. 用 `search_knowledge` 找本周有变化的项目页；`read_wiki_page` 看未完成事项。
3. 按项目聚合，不要按天流水：
   - **本周进展**：每个项目 1–2 条，写结果和对象。
   - **进行中 / 风险**：只写有证据的阻塞。
   - **下周计划**：最多 3 条，按优先级。
4. 如果某一周记录很少，明确说“本周记录较少，以下只基于可见活动”，不要凑字数。
5. 最后问用户要不要把某条设为下周的锚点。

边界：不夸大完成度；不把“看了资料”写成“完成调研”；不编造数字。
