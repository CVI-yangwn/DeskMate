# 调试时间线

目标：把“我到底试过什么”变成可读的时间线，帮用户找到重复或遗漏。

步骤：

1. 调用 `lookup_activity`，先取最近 120 分钟；不够再取 360 分钟。
2. 从记录里挑出与当前 bug 相关的片段：终端、IDE、浏览器、测试结果。
3. 按时间输出：
   - `HH:MM` 做了什么（一句话）
   - 关键变化：报错从 A 变成 B、测试从红变绿、文件被换掉
4. 最后给一个“下一步最值得试的”动作，并说明依据。
5. 如果发现同一个报错出现过 3 次以上，明确说“这一步在重复”，并建议换假设。

边界：只写记录里出现的应用、文件、报错；不猜代码内容；不把“看了文档”说成“改了代码”。
